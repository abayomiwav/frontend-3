# Code of Conduct

Be respectful, be constructive, assume good faith. Disagreement about
code, design, or architecture is normal and welcome; personal attacks,
harassment, and discriminatory language are not.

Report unacceptable behavior by opening an issue or contacting the
maintainers through the StellarExpress GitHub organization. Reports
will be handled discreetly, and maintainers may remove comments,
commits, or contributors who violate this standard.
