# Acknowledgements

Built with [Next.js](https://nextjs.org/), [React](https://react.dev/),
and [Tailwind CSS](https://tailwindcss.com/) for the interface;
[Framer Motion](https://www.framer.com/motion/) for animation;
[Recharts](https://recharts.org/) for the product preview's charts;
[React Hook Form](https://react-hook-form.com/) and
[Zod](https://zod.dev/) for form validation; [Radix UI](https://www.radix-ui.com/)
primitives for accessible interactive components; and
[lucide-react](https://lucide.dev/) for icons.

Talks to the [StellarExpress backend](https://github.com/StellarExpress/backend),
which enforces the escrow logic defined in
[StellarExpress/contracts](https://github.com/StellarExpress/contracts) on
the [Stellar](https://stellar.org/) network.
